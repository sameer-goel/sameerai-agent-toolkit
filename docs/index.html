How It Works

User prompt arrives via Claude Code hook
2
Model Router classifies: Haiku (reads) / Sonnet (dev) / Opus (architecture)
3
Skill Matcher fuzzy-matches intent against 30+ registered skills
4
Agent executes with full memory context (semantic + episodic + working)
5
Auto-capture persists decisions, corrections, files for next session

Components

Model Router Python production
Regex-based classifier. Reads prompt, matches against Opus signals (architecture, security, tradeoffs) and Haiku signals (reads, searches, renames). Routes to correct model tier. No LLM call, pure pattern match.
Skill Matcher Python production
Scans all skill directories, extracts keywords from SKILL.md descriptions, fuzzy-matches against user intent, injects top matches as context. Agent discovers capabilities on every prompt.
Memory Protocol production
Three-layer persistence: semantic (cross-session, manual prune), episodic (per-tab, auto-prune at 50 facts/7d/30d), working (current turn). Frontmatter-based format with typed categories.
Backend Switcher
Manages multiple AWS Bedrock profiles. Swap between free/paid/isolated accounts with one command. Settings stored as named JSON configs, copied to active on switch.
Task Router
Classifies task intent and dispatches to correct execution backend. Enterprise tasks, coding tasks, and planning tasks each go to their optimal environment. Human approves routing.
